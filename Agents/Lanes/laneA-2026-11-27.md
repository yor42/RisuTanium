## Merge recipe

1. Compare the reviewed snapshot or patch with the PR commit; new untracked files are checked by blob hash.
2. Run the lane A check (template `Agents/Handoffs/lane-a-pr-check.template.js` in the main checkout; Sonnet lenses unless a critical contract changed).
3. `git merge-tree --write-tree --name-only <head> origin/main` must be clean; check Refs versus Closes.
4. CI green on the exact head.
5. `gh pr merge N --repo yor42/RisuTanium --merge --match-head-commit <sha>`.
6. `git show --remerge-diff --format= <merge>` must be empty.
7. Remove the worktree (MC-4189): `cmd /c rmdir <wt>\node_modules`, `git worktree remove <wt>`, `git branch -d <branch>`.
