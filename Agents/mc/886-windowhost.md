### MC-4763 - #886: the windowing host watches its root from the first read without layout

A windowed list in a hidden tab panel (Studio display form, Assets tab) is read without layout, mounts no row, and used to have no ResizeObserver because only a mounted row created one, so showing the panel re-read nothing until a scroll, resize, key change or `refresh()`. `readGeometry` now calls `ensureObserver()` when a read finds no layout, so the root's size report re-reads the band. A host whose segments are all laid out and fixed still constructs no observer. Maintainer-level scope ruling by lane A: Tier 2 (shared host, 14 consumers, no persisted format), fix kept to the observer plus one regression test; the call sits in `readGeometry` instead of `slot.bind` because `bind` would break the pinned guard that a fixed segment constructs no ResizeObserver. Gate 1 and Gate 2 by fresh Sonnet reviewers; no critical contract.
