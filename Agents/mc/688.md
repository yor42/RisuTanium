### MC-4341 — #688 S3: memory-only vectors, re-embed spend accepted, 2026-11-27

- Tag: product (maintainer, AskUserQuestion). Date: 2026-11-27. Related: `#688`, `MC-2657`, `MC-350`.

**Decision.** S3 keeps dense vectors in memory only. Nothing is persisted, nothing joins `.bin` or `.rtb`, and the hypaVector store is not written (its `addText` keys hold message text and the store travels in `.rtb`). The background API spend of re-embedding the dropped history after an app start or a chat open is accepted, with the measured projection in the PR. Whether to persist vectors (a device-local quantised store with eviction) is decided after the 5,000-message measurement and is a persisted-format decision for the maintainer.

**Consequence.** Spec 3.3's "use the hypaVector store provisionally" is replaced by memory-only for S3.

### MC-4343 — #688 S3: orchestrator technical rulings from Gate 1 round 1, 2026-11-27

- Tag: technical (ticket session). Date: 2026-11-27. Related: `#688`, `MC-2814`.

**Decision.** Hybrid applies only when the engine injects; shadow mode stays lexical. The dense list is cut at the top 200 with no similarity floor. Dense stores live per chat in a map capped at 2 chats, so A-B-A switching does not re-embed. A failed or timed-out embed pauses dense for 60 s, and for 10 min on an auth or quota error; the reason is traced. A paused or timed-out query embed also gates the next queries for that window. Units embed their stored unit text. A local model is allowed on desktop and refused on phones until S3a passes.

**Consequence.** These are tuning constants, not stored format. Each is revisable from the trace data.

### MC-4344 — #688 S3: English-only warning and Rebuild scope, 2026-11-27

- Tag: technical (ticket session). Date: 2026-11-27. Related: `#688`, `MC-4340`.

**Decision.** The English-only model warning shows whenever hybrid is on and the embedding model is English-only; it never inspects chat content, and its wording names Korean. Rebuild index also drops that chat's vectors (it calls `discardChroMemoryIndex`, which disposes the store and drops the indexing job). A batch that does not settle in 30 s pauses dense for 60 s and releases the indexer's token; at most 2 batches stay unsettled.

**Consequence.** Tuning constants and UI wording only, no stored format. Base defect left alone (MC-091): embedding fetches have no timeout; a follow-up ticket should thread `requestTimeoutMs` through `HypaProcesser`.
