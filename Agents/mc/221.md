- Tag: decisions (session, Tier 1 under the ticket's own scope). Date: 2026-11-27. Exact times: UNKNOWN. Sweep ref: none. Related: `#221`, `MC-3779`.

**What was decided.** `StudioAssetList.svelte` requests a thumbnail or player URL only for rows whose key `windowHost.mountedKeys` holds (the band plus the pinned rows); every other row asks for nothing until it scrolls near the band. The per-run `createWholeReadBudget` admission is unchanged: a run now covers a window of rows, so the 64 MB budget counts those thumbnails at admission. No persisted format, save path or migration changes. `StudioEmotionList.svelte` has the same pattern and is not part of this ticket.

**Evidence.** Targeted tests: `StudioAssetList.window.svelte.test.ts` G16 and G17 fail on the base (200 and 3000 requests at open) and pass after; the 12 `StudioAssetList*` test files pass (210 tests); `svelte-check` reports 0 errors. The 3000-row open time of at most 200 ms is not measured here (jsdom time is not device time) and is owed as a Note 9 row.
