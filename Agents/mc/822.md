### MC-4754 — #822: a regenerate that will generate is amber, not red; red stays for errors, 2026-11-28

- Tag: decisions (maintainer via AskUserQuestion in the #822 session, two answers). Date: 2026-11-28. Exact times: UNKNOWN. Related: `#822`, `MC-2506`, `MC-4752`.

**What the maintainer chose.** First "apply the rule to the non-tree buttons", with the remark that red should mean error or problem, so regenerating should use yellow or light blue. Then "Amber, fixed Tailwind amber-400 (Recommended)". This amends `MC-4752`: the colour is `text-amber-400` instead of `text-draculared`, it stays on hover (the blue hover no longer hides it), and the same rule applies to the non-tree buttons (no visible change today, since none of them generates). The theme has no yellow or light-blue token, so the colour is fixed and a pack cannot retheme it. The old `text-draculared` assertions in `Chat.tree.svelte.test.ts` change to the new class. Also answered: new strings accepted as worded, and the empty text shows for group and playground chats with 0 messages only.
