### MC-4680 — #685 S7-3: a below-version-2 import entry whose migration would throw is skipped and counted, 2026-11-28

- Tag: decisions (maintainer, AskUserQuestion in the #685 S7-3 session, from the designer's open question OQ1). Date: 2026-11-28. Exact time: UNKNOWN. Related: `#685`, `MC-4004`, `MC-4080`.

**What the maintainer chose.** "Skip it, count it (Recommended)": when a Studio lore import into a character or module list meets an entry below version 2 whose `content` is not a string (so the version migration would throw), the entry is left out and counted in the "Skipped N items" notice. The other entries import in the same step. Studio never writes an entry that would make the next character selection throw. The check runs before ids and folder keys are assigned, so a skipped entry never takes an id, a folder key or a remap.

### MC-4681 — #685 S7-3: a file that fails to parse in a several-file import writes nothing, 2026-11-28

- Tag: decisions (maintainer, AskUserQuestion in the #685 S7-3 session, OQ2). Date: 2026-11-28. Exact time: UNKNOWN. Related: `#685`, `MC-4004`.

**What the maintainer chose.** "Write nothing, show the error (Recommended)": when any picked file fails to parse (bad JSON, or a PNG with no lorebook), the Studio import writes no entry from any file and shows that file's error (the existing no-data message for a PNG without a lorebook). One import stays all or nothing. The classic module menu keeps its partial append.

### MC-4682 — #685 S7-3: Studio Export is offered whenever the list has an element, 2026-11-28

- Tag: decisions (maintainer, AskUserQuestion in the #685 S7-3 session, OQ3). Date: 2026-11-28. Exact time: UNKNOWN. Related: `#685`, `MC-4003`.

**What the maintainer chose.** "Whenever the list has an element (Recommended)": the Export button is available on every host while the list shows at least one element, read-only lists included, because export writes nothing. An empty or absent lorebook disables it. This differs from the classic editor, which exports an empty list as `[]`.
