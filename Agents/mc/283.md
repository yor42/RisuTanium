### MC-4543 - Member map details: snapshot at removal, slots, key, lenient read, 2026-11-27

- Tag: decisions (maintainer via AskUserQuestion "Accept all", relayed by lane A). Date: 2026-11-27. Exact times: UNKNOWN. Related: `MC-4540`, `MC-4541`, `MC-350`, `DD-064`, `#283`.

**What the maintainer chose.**
- (Superseded by MC-4544) Refresh: write at join; snapshot the latest name at every fork-side permanent removal (single delete, empty trash, startup purge). Known limits: plugin-side or upstream-side removal and archived groups keep the join-time name.
- Slots: first free of 8; tombstones hold no slot; a 9th member takes the slot held by the fewest current members (lowest on a tie); a rejoin keeps its previous slot when no current member holds it, else first free. Removing a member with no record creates none.
- Key `risutanium_members`, typed unknown, read leniently: a malformed map or record reads as empty and is never overwritten.
- Generation-info dialog: resolved name, then the id in parentheses, no new locale key.
- Other findCharacterbyId name readers stay unchanged; the hypa query name fix in `addinfo.ts` applies to live members too.
