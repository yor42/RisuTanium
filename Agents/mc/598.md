### MC-4300 — #598 Script redraws re-parse the chat body instead of remounting it, 2026-11-27

- Tag: decisions (session, Tier 1 sizing; no maintainer question needed). Date: 2026-11-27. Exact times: UNKNOWN. Sweep ref: none. Related: `#598`, `#203`, `MC-175`, `MC-1064`, `MC-3618`.

**What was decided.** Lua `reloadDisplay`, the `v2UpdateGUI` effect and the varChanged completion of a trigger run call `redrawGuiSoft()` (`src/ts/process/softRedraw.ts`) instead of bumping `ReloadGUIPointer` alone. It raises a soft redraw count and then the pointer, so every other pointer reader (background, toggles, Studio, shell rows) refreshes as before. The classic chat row key is the pointer minus that count, so a script redraw no longer remounts `ChatBody`; Chat.svelte raises its render revision instead, `ChatBody` parses again and writes no DOM when the HTML string is equal, so a running animation or an open popup survives a redraw that changes nothing it shows. A redraw whose HTML changed still shows the new HTML. Any other pointer bump (module settings, regex edits, chat switch) still remounts. Size: Tier 1: contained UI logic, no persisted format, save path, migration or security boundary.

**Known limitation.** The pointer's own subscriber still empties `ReloadChatPointer` when it holds entries, so a row that was reloaded by index (`reloadChat`, `v2UpdateChatAt`) before the redraw remounts once, as it did before.
