### MC-TBD-613a — #613: the Home Tasks tab lists previews and backgrounded task cards, 2026-11-27

- Tag: decisions (maintainer, AskUserQuestion in the #613 session; ID to be assigned by lane A, no block was given to the session). Date: 2026-11-27. Exact times: UNKNOWN. Related: `MC-2825`, `MC-2936`, `MC-2937`, `MC-3669`, `MC-3672`, `#234`, `#613`.

**What the maintainer chose.** The Tasks dialog gets a second tab, Background, beside Replies. It lists prompt previews and task cards that were sent to the background (imports, exports, backups, restores, chat screenshot). Other work stays out: `work` registrations (takes, trigger runs, auto mode, multisend), Utility runs, dense and lore indexing, TTS, MCP and Studio hashing have no reactive list, label or progress, and keep their own UI. A preview row shows the chat and a Stop that ends that chat's work (MC-3669). A task row shows its title, subtitle and progress line, with Open (brings the card back) and Cancel while the card still offers it. A row leaves when its job ends (MC-2937); a result stays in its existing toast. The Tasks button badge and its accessible name count replies only; each tab label carries its own count, shown at zero too. The dialog opens on Replies, unless no reply runs and Background has rows. The dialog title is "Tasks".

**Consequence.** With only background work running the button shows no badge; the user opens it to see the work. Cancel from Home aborts a running import with its card out of view; the result toast is the single report. The new tab, Cancel and Open parts are not in the Home reach registry (`HOME_REACH_DD243`), so a theme pack can hide them (MC-3638, known limitation, no new guard).
