### MC-4500 — #686 S8: the group form is a memory-only session owner kind with name, members and orderByOrder, 2026-11-27

- Tag: decisions (maintainer, AskUserQuestion via lane A, all six answers were the recommended option A). Date: 2026-11-27. Exact times: UNKNOWN. Related: `#686`, `MC-3900`, `MC-3901`, `MC-1119`.

**What the maintainer chose.**
- Scope (OQ-a): name, members and `orderByOrder` only, as classic's group Basic tab. Nickname, hide-chat-icon, lore, regex, display and first message are not in S8.
- Reorder (OQ-b): none; classic has none.
- Greeting (OQ-c): none in Studio; adding a member never touches the chat.
- Archived members (OQ-d): remove, talk and active are allowed on them; add restores an archived candidate as classic does; a member is never dropped except by the user's own remove.
- History (OQ-e): memory-only session kind `group`, like the preset kind. A page reload loses member Undo. No persisted-format change, no store key, no record field.
- Save chip (OQ-f): none in S8.

**Consequence.** The three parallel arrays (`characters`, `characterTalks`, `characterActive`) change only together, one history step per user action. A stored `character:<groupId>` stays restricted (L5). A later move to a persisted group history would be a persisted-format change.

### MC-4501 — #686 S8: a Studio visit on a group shows the group only, 2026-11-27

- Tag: decisions (maintainer, AskUserQuestion via lane A). Date: 2026-11-27. Exact times: UNKNOWN. Related: `#686`, `MC-4500`.

**What the maintainer chose.** Option A: a Studio visit on a group shows the group only, one form (name, members, orderByOrder). No modules, presets, plugins, chat or merged lore, regex and toggle views. Modules stay reachable from a character's visit and from classic. The alternative was to list modules, presets and plugins under a group as for a character.

**Consequence.** The group owner model has one node with the `basic` kind. The combined-view, module-lore-pane and toggle-consumer surface is out of scope. The lore-used tap and the toggle link target keep opening classic for a group.
