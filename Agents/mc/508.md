### MC-4254 — #508 Chunk merging makes boot slower on the Note 9 and is not shipped, 2026-11-27

- Tag: decisions (session, measured experiment requested by lane A). Date: 2026-11-27. Exact times: UNKNOWN. Sweep ref: none. Related: `#508`, `MC-4252`.

**What was decided.** The one build-config chunk-merging experiment (155 startup files into 2, one 8.8 MB app chunk, nothing under `src/` changed) is not shipped: boot to Home paint is about 400-450 ms slower than main (medians 2641 against 2186-2251 ms on interleaved runs), return is unchanged. Merging files does not remove the module-graph cost, and compiling one large file at startup adds to it. The P4 edits show no gain the harness resolves (boot 2134 against 2186-2251, inside the 65 ms A-against-A spread), so the PR states that.

**Evidence.** `Agents/Findings-2026-11-27-508-home-boot-phase1.md`, addendum 3 (5 runs per cell, interleaved A, P4, CM, A).
