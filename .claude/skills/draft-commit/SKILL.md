Run this procedure in the parent. For a routine supplied-evidence message, register workClass records / mode implement directly as native record-clerk, Haiku low; no external preflight is required. Use a scratch draft without an application-write grant. This is the primary records exception, not a Claude relay. See [parallel tracks](../../../docs/workflow/2026-11-03-parallel-tracks.md) and [subscription-first execution](../../../docs/workflow/subscription-first.md).

Draft the routine commit message requested: $ARGUMENTS
Use only supplied change/verification evidence; write the message text to the named scratch draft/report, without repository or git mutation. Omit unsupported technical assertions and retain material qualifications. Evidence gaps or complex technical/persistence messages return to doc-writer through the Orchestrator. Ordinary facts use independent routine verification at the consuming gate; opus-reviewer owns claims about actual changed critical contracts within its existing gate. This invocation never authorizes committing.
