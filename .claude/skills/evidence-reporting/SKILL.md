---
name: evidence-reporting
description: Defines compact source-backed query, enumeration and verification reporting without upgrading confidence.
user-invocable: false
---

Report exact scope, inputs/exclusions, commands and snapshot/platform checked. Every enumeration states raw count, listed count and COMPLETE/PARTIAL with omissions. Zero matches are a result. If supplied commands miss intent, preserve their original result and name adaptations separately; no silent query substitution.
Separate observations from interpretations, traced from inferred, and independently verified from accepted evidence. Preserve CONFIRMED/REFUTED/UNCERTAIN or the packet's existing confidence. Judge query coverage before trusting counts; maps are leads and absence within one query is not absence everywhere.
Cite decision-relevant facts with file:line or command/result. Reopen primary source for behaviour claims, and resolved dependency source for load-bearing runtime behaviour. Report stale citations and violated expectations.
A pass requires actual command evidence: command, relevant output/exit status and what changes it tested. Do not imply offline/mocked checks prove native/live paths, or that a guard passing before/after reproduces a fixed defect. Label execution versus reasoning.
Return compact findings plus consequences, unresolved questions and the exact observation needed. Missing documentation evidence stays TODO(evidence), never invented. Keep heavy logs and disposable probes outside the repository.
Repository code/test comments name functions, effects and branches, not in-repo line numbers. Dated reports may cite file:line; pinned third-party source may cite versioned lines.
