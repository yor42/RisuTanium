Consult [Agents/README](../../../Agents/README.md) for authority. Maintainer-Context records maintainer facts/decisions; Roadmap owns scope/sequencing; ledger owns dispatches/cost/results; reports/gate records hold evidence; Live-State is current state, not history. Read only relevant entries.
Preserve stable MC/report/ledger IDs and append-only history. Never renumber, reorder or silently rewrite authoritative old decisions. Supersession must be explicit at the rule source with its record, not a competing exception. No routine clerk may invent or append a maintainer decision or governance change.
Directly register the primary native Haiku record-clerk for new workClass records / mode implement, without external preflight. Supply a bounded frozen facts packet, exact quotations/reserved IDs, target anchors/schema, accepted gate/test provenance and limits. One records drafter runs beside two code worktrees and a device track; only actual ownership/resources/dependencies serialize. Ordinary exact-grant Markdown may be edited; authoritative decisions/governance/index/state changes return as scratch text for parent application. Existing guard exclusions stay. Missing facts remain TODO(evidence); hard judgement returns to its responsible role. No hidden model upgrade or self-acceptance.
Match named record/table schema and line endings; preserve pre-existing work. Keep English documentation and source evidence confidence/provenance. Drafts are not accepted records; never invent dates, tokens, commands, passes or verdicts.
Technical acceptance and administrative closeout are distinct. An item is COMPLETE only after applicable decisions, independent gate dispositions, Roadmap/status and current-state/remaining-work records are current. Name a record owner and check only the applicable records; do not invent an MC decision or reconcile all history for a tiny correction. Follow [item records](../../../docs/workflow/records.md).
Closeout names scope/amendments, actual verification snapshot, independent gate verdicts, accepted limitations and remaining uncertainty. Changed record claims receive independent claim/diff verification against accepted evidence; a missing record blocks administrative closeout, not technical behavior. Do not restart Gate 2 or rerun application tests unless closure exposes a substantive defect or invalidates accepted evidence. Do not mutate records outside the brief.
Future selected reproducible evidence belongs in Agents/Evidence/<item-id>/ with a README naming artifact role, claim, provenance, base plus working/untracked changes, dependencies/runtime/configuration/inputs, observed results/limits and exact run recipe. Raw transcripts and temporary outputs stay local scratch, normally outside the repository. Preserve legacy tracked history and the raw handoff. Never remove an only-copy source before independently reviewed extraction and retention of needed operational evidence. Existing protected community-code directories remain protected; selected evidence must be safe to publish.
[Decision-Index](../../../Agents/Decision-Index.md) is generated navigation only, not a summary or supersession register. After MC additions, regenerate using `pwsh -NoProfile -File .claude/scripts/update-decision-index.ps1`; check freshness with the same command plus `-Check`. Literal MC headings are authoritative; index titles convey no current status.
