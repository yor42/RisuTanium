    3. Launcher icon (SPEC §7)

    Masks are approximations (squircle is a plain rounded rectangle at 34%). The current icon is a legacy square PNG, so it is shown clipped by each mask; real launchers may shrink or backplate it. Themed monochrome is shown on two example wallpaper tints (Android 13+).

    D-10OPEN Sequence: splash, loading background until first paint, then the boot screen. Instant colour swaps; a short crossfade only without reduced motion.
